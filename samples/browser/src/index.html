FaultLens Browser SDK Sample

Validate browser-side diagnostic evidence before adding the SDK to your app.

This framework-free TypeScript sample uses to demonstrate setup, breadcrumbs, route/page context, identity, manual capture APIs, network breadcrumbs, and redacted values.

Setup

Use your FaultLens endpoint or tenant host. The SDK posts to /api/events/ingest when a host is provided.

Do not commit real keys. This sample only reads values from local runtime configuration.

    What to verify in FaultLens

    1. Captured messages and exceptions include service name, service version, environment, release, and SDK metadata.
    2. Breadcrumbs show UI clicks, navigation changes, custom flow steps, and safe network metadata.
    3. Route/page context shows Dashboard or Checkout with the previous path when changed.
    4. Identity fields use opaque demo IDs only.
    5. Redaction demo values appear as redacted values, not raw token/password/apiKey strings.
